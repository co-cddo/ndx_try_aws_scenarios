# Change of use

Changing the use of a building or land may need planning permission. The Town and Country Planning (Use Classes) Order 1987 (as amended) groups uses into classes. Movement within the same class is not "development" and does not need permission. Movement between classes may need permission, may be permitted development, or may not be a material change at all.

## Use classes (England, post-2020 reforms)

- Class B2: General industrial
- Class B8: Storage and distribution
- Class C1: Hotels
- Class C2: Residential institutions (care homes, hospitals, boarding schools)
- Class C2A: Secure residential institutions
- Class C3: Dwellinghouses (a, b, c sub-categories)
- Class C4: Houses in multiple occupation (small, 3-6 unrelated occupants)
- Class E: Commercial, business and service (covers former A1 shops, A2 financial, A3 restaurant, B1 offices, D1 non-residential institutions, D2 indoor sports)
- Class F1: Learning and non-residential institutions
- Class F2: Local community uses (small shops, halls, swimming pools)
- Sui generis: pubs, takeaways (formerly A5), nightclubs, cinemas, casinos, betting offices, scrap yards, taxi businesses

## Worked examples

A1 to A3 (old terminology): Both are now within Class E since 1 September 2020. No planning permission needed for the use change itself, although building works (extraction, ducting, signage) may need consent.

Pub to restaurant: pubs are sui generis, restaurants are Class E. Permission required.

Office to dwelling: covered by Class MA prior approval (since August 2021). Limits on size, vacancy, location apply.

Takeaway to shop: takeaways are sui generis, shops are Class E. Permission required.

Dwelling to small HMO (C3 to C4): permitted development in most areas, BUT Aldershire has an Article 4 direction in the Aldermarket University Quarter (since 2019) that withdraws this PD right. Permission required there.

## How to check

The bot does not classify use changes. Always:

1. Check the existing lawful use (Lawful Development Certificate may help)
2. Use the Planning Portal "Do I need permission?" tool
3. Get pre-application advice from Aldershire (see separate document)

## Fees

Change of use planning application: GBP 578 per 0.1 hectare (with caps). Class MA prior approval: GBP 125. Pre-application advice: see fee schedule.
